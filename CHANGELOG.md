All notable changes to this project are documented here. The format follows

## [Unreleased]

### Added
- Reading mode: Markdown documents shown nicely formatted (tables, checklists, code highlighting,
  local and web images), with clickable checkboxes and links.
- Editing mode with a formatting toolbar, keyboard shortcuts and a live, scroll-synced preview.
- Pasting from web pages, Word or Google Docs keeps the formatting (converted to Markdown); pasted
  and inserted images are copied into an `images` folder next to the document.
- Export as a standalone web page, print or save as PDF.
- Welcome screen with recent documents, drag and drop, one window per document.
- Settings: theme, language (English, French), text size, reading font, autosave, spell check.
- "Open .md files with Plume" in the settings, offered once at first launch.
- Packages for macOS (universal dmg), Windows (installer) and Linux (AppImage, deb, rpm).
